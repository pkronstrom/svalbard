# p5.js 1.x

Creative coding on a canvas: shapes, colour, motion, noise, mouse and keyboard. This is p5.js 1.11 (with `preload()`), not 2.x. Use instance mode, as below, so the sketch works once packed. Pack the page with `svalbard-drive html pack`; never link a CDN.

## Import

```js
import p5 from "p5";
```

## Example

```html
<!doctype html>
<html><head><meta charset="utf-8"><title>Sketch</title></head>
<body>
<script type="module">
import p5 from "p5";
new p5(s => {
  let t = 0;
  s.setup = () => { s.createCanvas(600, 400); s.noStroke(); s.randomSeed(42); s.noiseSeed(42); };
  s.draw = () => {
    s.background(250, 245, 235, 25);
    for (let i = 0; i < 40; i++) {
      const x = s.noise(i * 0.1, t) * s.width, y = s.noise(i * 0.1 + 100, t) * s.height;
      s.fill(74, 124, 89, 120);
      s.circle(x, y, 12);
    }
    t += 0.005;
  };
});
</script>
</body></html>
```

## Notes

- Every p5 function is a method of the sketch: `s.circle`, `s.fill`, `s.random`, `s.mouseX`.
- `s.preload = () => { img = s.loadImage(dataUrl) }` loads before `setup`; import the image file into the page (it arrives as a data URL) instead of naming a path.
- `s.randomSeed(n)` and `s.noiseSeed(n)` make a sketch repeat exactly. `s.saveCanvas("sketch", "png")` downloads a frame.
