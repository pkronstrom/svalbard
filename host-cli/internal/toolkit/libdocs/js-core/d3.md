# D3

Data-driven SVG: scales, axes, shapes, and map projections that draw GeoJSON (a choropleth). Write the page with a bare import and pack it with `svalbard-drive html pack`; never link a CDN.

## Import

```js
import * as d3 from "d3";
```

## Example: choropleth from GeoJSON in the page

```html
<!doctype html>
<html><head><meta charset="utf-8"><title>Map</title></head>
<body>
<svg id="map" width="800" height="420"></svg>
<script type="module">
import * as d3 from "d3";
import world from "./countries.geojson";   // packed into the page; no fetch
const svg = d3.select("#map");
const projection = d3.geoNaturalEarth1().fitSize([800, 420], world);
const path = d3.geoPath(projection);
const values = world.features.map(f => f.properties.POP_EST).filter(v => v > 0);
const color = d3.scaleSequentialLog(d3.interpolateYlOrRd).domain(d3.extent(values));
svg.selectAll("path").data(world.features).join("path")
  .attr("d", path)
  .attr("fill", f => f.properties.POP_EST > 0 ? color(f.properties.POP_EST) : "#ccc")
  .attr("stroke", "#fff")
  .append("title").text(f => `${f.properties.NAME}: ${d3.format(",")(f.properties.POP_EST)}`);
</script>
</body></html>
```

Import a `.geojson`, `.json` or `.csv` file next to the page as shown: `svalbard-drive html pack` puts its contents in the page (`.csv` and `.txt` arrive as text: parse CSV with `d3.csvParse(text, d3.autoType)`). Do not use `d3.json("file")` or `d3.csv("file")`: they fetch, and a page opened by double-click cannot fetch files.

## Notes

- Bars: `d3.scaleBand()` for categories, `d3.scaleLinear()` for values, `d3.axisBottom(x)` and `d3.axisLeft(y)` drawn into `<g>` elements.
- Projections: `d3.geoNaturalEarth1()`, `d3.geoMercator()`, `d3.geoEqualEarth()`; `fitSize([w, h], geojson)` frames the data.
- A legend: draw a few `<rect>` swatches with `color(value)` for chosen values.
