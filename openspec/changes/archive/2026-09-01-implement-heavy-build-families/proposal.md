## Why

Reference data, compact ZIM, zimit routing, and vector geodata recipes remain declared but non-executable or partially routed after the foundation. This slice adds concrete handlers where source contracts are already sufficient and separates unresolved map families.

## What Changes

- Implement Fimea reference-static XML-to-SQLite ingestion.
- Implement zim-compact Go orchestration through tools-base writer/checker calls.
- Route existing zimit procedures through the browser target.
- Implement vector-static and vector-service Go handlers through typed tools-base calls.
- Reject missing family data before effects.

## Capabilities

### New Capabilities
- `heavy-build-families`: Fimea, compact-ZIM, zimit routing, and vector geodata recipes have concrete Go-controlled paths.

### Modified Capabilities

None.

## Impact

Depends on `go-builder-pipeline`. No host packages or end-machine Docker requirement.
