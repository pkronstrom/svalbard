## Why

The Make It Yourself recipe names a large Python builder that current Go apply ignores. Its crawl is valuable but mixes HTTP, PDF extraction, site-specific metadata, browser fallback, optimization, and ZIM writing in one script.

## What Changes

- Port maintained HTTP, HTML, metadata, PDF, state, and orchestration responsibilities to Go.
- Preserve site-specific behavior as colocated Go strategies.
- Route Chromium and ZIM writer effects through typed tools capabilities.
- Preserve interruption/resume and output quality checks.

## Capabilities

### New Capabilities
- `miy-go-builder`: The MIY recipe builds reproducibly through Go orchestration and pinned browser/writer tools.

### Modified Capabilities

None.

## Impact

Depends on the builder foundation and heavy ZIM/browser family seams. The existing Python script remains until parity is proven.
