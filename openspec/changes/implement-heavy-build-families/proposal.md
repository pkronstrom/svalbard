## Why

ZIM writing, website crawling, geodata, and structured-reference recipes remain declared but non-executable after the builder foundation. They require family-specific Go orchestration over the pinned tools appliances.

## What Changes

- Implement reference-static ingestion from typed table declarations.
- Implement zim-compact orchestration through tools-base.
- Implement zimit through tools-browser.
- Implement retained vector, raster, OSM, and MML geodata families through typed tools-base commands.
- Add real-image integration scenarios and resource estimates.

## Capabilities

### New Capabilities
- `heavy-build-families`: Retained ZIM, crawl, geodata, and reference recipes produce verified artifacts through concrete Go handlers.

### Modified Capabilities

None.

## Impact

Depends on `go-builder-pipeline`. No host packages or end-machine Docker requirement.
