# Offline maps data and local AI models/tools missing from Svalbard's catalog (as of 2026-11-26)

Baseline checked first (so items below are gaps only):
- Maps recipes (11): `osm-finland` / `osm-uusimaa` (Protomaps daily-build extracts, `osm-extract` family, z14–15), `mml-maastokartta` (kapsi TMS raster, Uusimaa bbox), `mml-map-sheets`, `mml-topo-uusimaa` (MTK vector), `natural-earth` (gpkg), SYKE/LUKE/LIPAS thematic layers. Tools: `go-pmtiles` v1.31.2, `maplibre-vendor` (MapLibre 5.24.0, pmtiles.js 4.5.0). No terrain, imagery, nautical, aviation, routing or geocoding data; no tile server other than go-pmtiles.
- Models recipes (13): Gemma 4 E2B/E4B/12B/26B-A4B/31B (unsloth QAT UD-Q4_K_XL), Qwen3.5 0.8B/4B/9B, Qwen3.6-35B-A3B, Qwen3.8-27B (IQ4_XS, Q6_K_XL, MTP drafter), `nomic-embed-text-v1.5` Q8_0 (256-dim matryoshka, used by `host-cli/internal/embedder/embedder.go` via `llama-server` in embedding mode; picks the first `.gguf` in `models/embed/`). All chat recipes are marked "text-only runtime" (no mmproj files shipped). No reranker, STT, TTS, translation or OCR models.
- Runtime: `llama-server` pinned to llama.cpp **b11146** (published 2026-09-23, described as v0.5.0). Packs: `ai/models-{8,16,24,64}gb-ram`, `ai/mtp`, `ai/harnesses` (llama-server, opencode, goose, pi).

## (1) Maps: what offline map data and tools does the catalog lack?

### Takeaway
The biggest gaps are terrain (Mapterhorn terrarium PMTiles, MML 2 m DEM / hillshade), imagery (MML orthophoto via kapsi TMS for Finland; VersaTiles / Sentinel-2 Global Mosaic for global), offline routing (BRouter rd5 segments are tiny: ~130 MB for Finland), and geocoding (Photon Finland dump, 244 MB). All of these have open licences that allow offline bundling; EOX Sentinel-2 cloudless does not (non-commercial share-alike), and openAIP aviation data is reported as CC BY-NC.

### Cited Findings

#### Basemaps (global and regional vector tiles)
- **Protomaps daily builds (planet / low-zoom world overview)**: hosted at maps.protomaps.com/builds (v4 channel); planet ≈120 GB, z0–15, ODbL produced work, OSM attribution required; the bucket keeps the past week of builds plus the latest per patch version; docs recommend `pmtiles extract --maxzoom` for cutouts and discourage hotlinking. Fit: the catalog already extracts Finland/Uusimaa from these. The gap is a **world overview extract** (for example z0–6 or z0–8) for global context next to `natural-earth`. Size: not measured (no pmtiles CLI on this host for `--dry-run`). — [Protomaps downloads](https://docs.protomaps.com/basemaps/downloads)
- **VersaTiles OSM vector planet**: `https://download.versatiles.org/osm-vector/osm-vector.versatiles`, 62.1 GB, z0–14, Shortbread schema, ODbL; dated snapshots (e.g. `osm-vector.20261027.versatiles`), with `.md5` and `.sha256` next to each file. Fit: an alternative global basemap that is half the size of the Protomaps planet, but in a different schema (Shortbread, not Protomaps v4), so the MapLibre style would need to change. — [download.versatiles.org](https://download.versatiles.org/)
- **VersaTiles landcover**: `landcover-vector/landcover-vector.versatiles`, 4.1 GB, z0–10, ESA WorldCover 2021 + OSM landuse, ODbL + CC-BY 4.0. Fit: a cheap global landcover overlay. — [download.versatiles.org](https://download.versatiles.org/)
- **VersaTiles bathymetry**: `bathymetry-vector/bathymetry-vector.versatiles`, 681.5 MB, GEBCO 2021 depth contours (Alpha); licence not stated on the download page. — [download.versatiles.org](https://download.versatiles.org/)
- **VersaTiles CLI** (`versatiles-rs`) v5.16.0 (2026-11-25), 20 release assets, including `versatiles-linux-gnu-x86_64` / `aarch64` tarballs and `.deb` packages. It converts and serves tiles. — [versatiles-rs releases](https://github.com/versatiles-org/versatiles-rs/releases)
- **OpenFreeMap**: offers **weekly** full-planet downloads in Btrfs, MBTiles and PMTiles; styles Positron, Bright, Liberty, Dark, Fiord, 3D; project MIT-licensed, data from OSM. A self-hosted planet is ≈170 GB. Exact download URLs and file sizes are not on the public pages. — [openfreemap.org](https://openfreemap.org/); [self-hosting doc](https://github.com/hyperknot/openfreemap/blob/main/docs/self_hosting.md)
- **Geofabrik Finland**: `finland-latest.osm.pbf` 742 MB; `finland-latest-free.gpkg.zip` 1.5 GB; experimental `finland-shortbread-1.0.mbtiles` 1.7 GB. Fit: the PBF is the input for any self-built routing graph (GraphHopper, OSRM, Valhalla). — [Geofabrik Finland](https://download.geofabrik.de/europe/finland.html)

#### Terrain, hillshade, contours
- **Mapterhorn**: terrarium-encoded RGB terrain as 512 px WebP tiles in PMTiles. Planet `https://download.mapterhorn.com/planet.pmtiles` covers z0–12; z13–17 come as per-tile archives (e.g. `6-33-22.pmtiles`), listed in `download_urls.json`. Regional extract: `pmtiles extract --bbox=… https://download.mapterhorn.com/planet.pmtiles out.pmtiles`. Global layer is 30 m; some regions have 0.25–1 m. — [Mapterhorn](https://mapterhorn.com/); [Data access](https://mapterhorn.com/data-access/)
- Mapterhorn planet size: HTTP `content-length: 355579263191` (≈355.6 GB), last modified 2026-09-11 (HEAD request on the planet URL, checked this session). — [planet.pmtiles](https://download.mapterhorn.com/planet.pmtiles)
- Mapterhorn licence: VersaTiles lists Mapterhorn as **CC-BY 4.0** and Copernicus GLO-30 under the Copernicus DEM licence. Third-party write-ups say the global layer comes from Copernicus GLO-30 up to z12. Mapterhorn's own attribution page did not render during this session. — [VersaTiles sources](https://versatiles.org/sources/); [search summary incl. dev.to/mierune](https://dev.to/mierune/building-a-3d-map-application-using-mapterhorn-terrain-data-elo)
- Protomaps docs point to Mapterhorn as the terrain companion to their basemaps; MapLibre (already vendored) renders terrarium `raster-dem` with hillshade and 3D terrain natively. — [Protomaps downloads](https://docs.protomaps.com/basemaps/downloads)
- **VersaTiles elevation raster**: `elevation-raster/elevation-raster.versatiles`, 331.2 GB (Beta, © Mapterhorn). **Hillshade vector**: `hillshade-vector/hillshade-vector.versatiles`, 105.4 GB (Alpha, Mapzen terrain tiles). — [download.versatiles.org](https://download.versatiles.org/)
- **Copernicus DEM GLO-30**: AWS open data bucket `s3://copernicus-dem-30m` (eu-central-1, no-sign-request); free licence; adapted or modified data must carry a specific notice. Licence versions are disputed (the AWS-linked licence may be outdated). — [AWS registry](https://registry.opendata.aws/copernicus-dem/); [COPDEM licence PDF](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM/resources/license/License-COPDEM-30.pdf)
- **MML (Finland) on kartat.kapsi.fi**, all **CC BY 4.0**: Korkeusmalli DEM at 2 m and 10 m (grid); Vinovalovarjoste hillshade at 2, 8, 32, 64, 128 and 512 m; Korkeusvyöhyke elevation zones; laser point clouds. These are **not** served as TMS and would need a builder. — [kartat.kapsi.fi](https://kartat.kapsi.fi/)

#### Satellite / aerial imagery
- **MML Ortoilmakuva (orthophoto, colour and CIR)**: CC BY 4.0, already served as TMS JPG on kapsi (EPSG:900913 and EPSG:3067). Fit: plugs straight into the existing `raster-tms` builder family that `mml-maastokartta` uses, with the same bbox approach. Kapsi also serves Peruskarttarasteri and Taustakarttasarja as TMS. — [kartat.kapsi.fi](https://kartat.kapsi.fi/)
- **VersaTiles satellite raster**: `satellite-raster/satellite-raster.versatiles`, 1.56 TB global (Alpha). Its listed sources are the Sentinel-2 Global Mosaic (CC-BY 4.0), NASA Blue Marble Next Generation (Public Domain) and some national orthophotos. Finland/MML is not among the orthophoto sources. — [download.versatiles.org](https://download.versatiles.org/); [VersaTiles sources](https://versatiles.org/sources/)
- **EOX Sentinel-2 cloudless 2024**: free tier is **CC BY-NC-SA 4.0**, via WMTS `tiles.maps.eox.at/wmts/1.0.0/WMTSCapabilities.xml`. Offline bundling is only addressed under the paid commercial licence (cloudless.eox.at sells GeoPackage/MapCache files). A 2025 edition is in development. Fit: **poor** (NC-SA, and terms for bulk offline download are unclear); prefer the CC-BY Sentinel-2 Global Mosaic or Blue Marble. — [EOX 2024 post](https://eox.at/2025/03/sentinel-2-cloudless-2024/); [search summary](https://cloudless.eox.at/)

#### Nautical and aviation
- **OpenSeaMap**: there is no maintained prebuilt download. The OSM wiki lists old regional MBTiles of about 0.5 GB each (Adriatic, Biscay, Channel). The community `vector-seamarks` pipeline filters OSM seamarks into vector tiles (MBTiles/PMTiles). OpenCPN needs PNG MBTiles, not WebP. Fit: build seamark vector tiles from the Finland PBF with the existing vector builder; ODbL. — [OSM wiki MBTiles](https://wiki.openstreetmap.org/wiki/MBTiles); [seamark vector tiles](https://wiki.openstreetmap.org/wiki/User:Kannix/seamark-vector-tiles)
- **Traficom (Finland)**: geodata is generally CC BY 4.0. Nautical charts fall under a hydrographic licence where **non-navigational** use is free and navigational use needs a contract. — [Traficom licences](https://traficom.fi/en/transport-system/geoinformationsmaterial/use-and-licences-data)
- **openAIP** (airspaces, airfields, navaids): export bucket organised by ISO country code (XML/GeoJSON). Licence reported as **CC BY-NC 4.0** by third parties (Airfield Directory FAQ). openAIP's own text could not be confirmed. Fit: non-commercial only. — [openaip.net](https://openaip.net); [Airfield Directory FAQ](https://airfield.directory/pages/faq)

#### Offline routing
- **BRouter segments (rd5)**: weekly planet regeneration at `https://brouter.de/brouter/segments4/`, in 5°×5° tiles. Finland-relevant tiles as of 2026-11-26: E20_N60 38.4 MB, E25_N60 38.8 MB, E20_N65 10.9 MB, E25_N65 10.0 MB, E30_N60 11.8 MB, E20_N55 22.3 MB, E25_N55 23.9 MB (plus E15/E30 edges). All of Finland is ≈130–180 MB. Engine: `brouter-1.7.10.zip` (2026-07-17, Java). Data ODbL; code MIT. Fit: **excellent size-to-value**, and it does profile-based bike, foot and car routing fully offline. — [segments4 listing](https://brouter.de/brouter/segments4/); [BRouter releases](https://github.com/abrensch/brouter/releases)
- **GraphHopper** 11.1 (2026-09-29): `graphhopper-web-11.1.jar` only; it builds its graph from a PBF (no prebuilt graphs found). Apache-2.0. — [GraphHopper releases](https://github.com/graphhopper/graphhopper/releases)
- **Valhalla** 3.9.3 (2026-11-17): no binary release assets; tiles must be built from a PBF. — [Valhalla releases](https://github.com/valhalla/valhalla/releases)

#### Geocoding
- **Photon Finland dump**: `https://download1.graphhopper.com/public/europe/finland/photon-dump-finland-1.0-latest.jsonl.zst`, 244.4 MB (2026-11-23), weekly dated snapshots (`release-261122`, …), with `.md5`. There is no Finland DB dump (JSON import only). Europe DB dump (1.x) is 32.2 GB, Europe JSON is 13.4 GB, planet DB (1.0) is 63.5 GB. — [Photon Finland](https://download1.graphhopper.com/public/europe/finland/); [Photon Europe](https://download1.graphhopper.com/public/europe/); [Photon planet](https://download1.graphhopper.com/public/)
- Photon 1.3.0 (2026-08-07), single `photon-1.3.0.jar`, **Java 21+**, Apache-2.0. A planet DB needs ≈95 GB of disk. — [Photon GitHub](https://github.com/komoot/photon); [releases](https://github.com/komoot/photon/releases)

#### Servers and viewers (single binaries)
- **Martin** (MapLibre tile server, Rust): v2.0.0-beta.8 (2026-11-25, pre-release) has prebuilt `martin-aarch64-apple-darwin.tar.gz`, `martin-{aarch64,x86_64}-unknown-linux-{gnu,musl}`, Windows and FreeBSD builds. The release notes cover PMTiles archives larger than memory, and font/sprite/style catalog entries. — [Martin releases](https://github.com/maplibre/martin/releases)
- **Organic Maps** `.mwm` data: community mirrors `https://omaps.webfreak.org/` and `https://omaps.wfr.software/`. Data is under the "Organic Maps Binary Data License" (DATA_LICENSE.txt); the app is Apache-2.0. BBBike offers weekly Organic Maps extracts. — [cdn.organicmaps.app](https://cdn.organicmaps.app/); [OSM wiki Organic Maps](https://wiki.openstreetmap.org/Organic_Maps)

### Inferences
- Best map additions, in order: (a) MML orthophoto raster recipe (reuses the `raster-tms` builder, CC BY 4.0, Finland-native); (b) Mapterhorn terrain extract for Finland or Uusimaa (`pmtiles extract`, needs no new tool, MapLibre renders it); (c) BRouter rd5 tiles for Finland (~150 MB) plus a routing UI, but the engine needs a JRE on the host and there is none in the catalog; (d) Photon Finland JSON dump (also Java 21); (e) a world-overview Protomaps extract at low zoom.
- Java dependency: BRouter, GraphHopper and Photon all need a JRE. If the drive runtime should stay Java-free, BRouter rd5 files remain useful for phone apps (BRouter Android, OsmAnd), and Photon could be swapped for a SQLite FTS index built from the same JSON dump.
- A Shortbread (VersaTiles/Geofabrik) basemap would need a second MapLibre style. Keep the Protomaps v4 schema the catalog already uses unless there is a reason to switch.
- MML DEM/hillshade (2 m) would make a much better Finnish relief layer than Mapterhorn's 30 m global layer, but it needs a new GeoTIFF→terrarium (or hillshade raster) builder.

### Gaps
- Exact Mapterhorn and Protomaps extract sizes for a Finland or Uusimaa bbox were not measured (no `pmtiles` CLI on this host; `pmtiles extract --dry-run` would answer it).
- Whether Mapterhorn includes MML high-resolution data for Finland: unconfirmed (its attribution page and JSON did not load).
- OpenFreeMap download URLs and sizes; OsmAnd `.obf` licence and per-region sizes; Organic Maps Finland `.mwm` size: not found.
- NASA Blue Marble and Black Marble resolutions and file sizes: the NASA page moved (301 to science.nasa.gov) and was not re-fetched; the only public-domain evidence is VersaTiles' source list.
- Traficom's actual download formats (S-57, raster, WMTS) for nautical data, and openAIP's licence text from openAIP itself: not confirmed.

## (2) Local AI: which models and runtimes released mid-2025 to Nov 2026 beat or complement the catalog?

### Takeaway
The pinned llama.cpp (b11146, 2026-09-23) is too old for the strongest new local models: Inkling 2 Mini and Raon-1-mini need the newest builds, which v1.1.0 (2026-11-26) supports. Upgrading `llama-server` is the prerequisite. The clearest non-LLM gaps are multilingual embeddings (EmbeddingGemma 2, Apache, 100+ languages including Finnish, versus English-centric nomic v1.5), a reranker (Qwen3-Reranker-0.6B), Finnish-capable STT (parakeet-tdt-0.6b-v3, Qwen3-ASR), Finnish TTS (Piper `fi_FI-harri`) and fi↔en translation (Hy-MT3, Apache, released 2026-11-24).

### Inferences
- **Step zero:** bump `llama-server` from b11146 to b12776 or later (v1.1.0). Without it, Inkling 2 Mini and Raon-1-mini will not load, and Kokoro TTS is unavailable. The MTP behaviour already measured on Apple Silicon should be re-checked after the bump.
- Candidate pack changes: **24 GB tier**: Inkling 2 Mini UD-IQ4_XS (15.7 GB) or Muse Glimmer UD-Q4_K_XL (15.9 GB) as a vision-capable general/agent model next to Qwen3.8-27B. **64 GB tier**: Nanbeige4.3-33B Q4_K_M (20.8 GB) as a coding alternative. **16 GB tier**: Mellum2.1 (8.1 GB) for coding. Raon-1-mini's explicit Pi support is relevant to the `svalbard` pi provider, but it is Korean-tuned and brand new. All of these need the measurement pass Svalbard did for Gemma/Qwen before they become defaults.
- **Embeddings**: EmbeddingGemma 2 Q8_0 (0.31 GB) is a drop-in candidate; set MRL to 256 dims to match current index shapes. It changes the vector space, so existing semantic indexes must be rebuilt (the search checkpoint requires exact-model reader compatibility). Its doc and query prompt names (`SearchQuery` etc.) differ from nomic's `search_document:` / `search_query:` prefixes.
- **Reranker**: Qwen3-Reranker-0.6B (0.64 GB) through llama-server's reranking endpoint would add a second stage to semantic search at little cost.
- **Voice stack, Finnish-capable and fully open**: parakeet-tdt-0.6b-v3 (CC-BY) or whisper large-v3-turbo q5_0 (MIT) for STT, Piper fi_FI-harri-medium (60 MB) for TTS. Qwen3-ASR via llama.cpp mtmd would avoid adding a second runtime. That llama.cpp can run Qwen3-ASR is inferred from the ggml-org GGUF + mmproj packaging, not confirmed in this session.
- **Translation**: Hy-MT3-1.8B Q4_K_M (1.35 GB) is the obvious small fi↔en model, runnable in the existing llama-server.
- **OCR**: GLM-OCR (1.4 GB total, MIT) is the best licence/size fit for scanned Survivor Library and Gutenberg PDFs.

### Gaps
- Whether llama.cpp loads prism-ml's custom ternary quant types (`PTQ1_0`, `PQ2_0`, `Q2_0`) and SenseNova-Loop-9B's looped architecture: not verified. Neither appeared in the v1.1.0 notes I read.
- No independent benchmarks were found for Inkling 2 Mini, Muse Glimmer, Raon-1-mini, Mellum2.1 or SenseNova-Loop against Svalbard's current Gemma 4 / Qwen3.8 picks. Most comparisons are vendor claims or SEO aggregator rankings (geotoolbox, gpuwerk), which disagree.
- OpenMDW-1.1 licence terms (Nemotron models) were not read. It is presented as an open licence but is not a standard OSI licence.
- Finnish quality for Hy-MT3, Inkling 2 Mini and EmbeddingGemma 2 is unmeasured. Hy-MT3's Finnish support is new in v3.
- Kokoro language list (believed to exclude Finnish) was not verified this session. Piper per-voice dataset licences (MODEL_CARD) were not read.
- No portable prebuilt whisper.cpp binaries exist on GitHub releases; whether llamafile's `transcribefile` or sherpa-onnx binaries fit Svalbard's binary recipe model was not checked in detail.
